## Навыки
- Анализ пользовательского поведения и продуктовых метрик
- Проведение A/B-тестов и статистических проверок гипотез
- Построение когортного анализа и расчёт Retention, Conversion, LTV
- Оптимизация бизнес-показателей на основе данных
- Подготовка аналитических отчётов и визуализаций
- Работа с большими объёмами данных (SQL, Python, Pandas)
- Автоматизация аналитических процессов (Airflow, скрипты Python)
- Управление версиями и командная работа (Git, GitHub)
